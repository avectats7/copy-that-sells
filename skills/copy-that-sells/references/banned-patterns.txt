# banned-patterns.txt — single source of truth for banned copy patterns.
#
# One place both tools read so their lists can never drift apart again:
#   - scripts/validate.py        (Python scorer; reads banned + jargon + superlative)
#   - ../../../evals/check_banned_words.py  (gate; reads banned + jargon + opener)
#
# Format, one rule per line:   LANG  CATEGORY  PATTERN
#   LANG      en | es
#   CATEGORY  banned | jargon | superlative | opener
#   PATTERN   an ERE (extended regex). May contain spaces; everything after the
#             second whitespace run is the pattern, so bash `read -r a b rest`
#             and Python `split(None, 2)` both parse it without a delimiter that
#             collides with regex alternation (|).
# Lines starting with # and blank lines are ignored.
#
# CATEGORY semantics:
#   banned       Hard AI-tell. Shell fails on it; scorer deducts heavily.
#   jargon       Corporate/AI word that can appear in prose. Shell fails on it
#                (it only ever scans curated copy); scorer deducts lightly.
#   superlative  Puffery that is legitimate WITH proof nearby ("best" + a stat).
#                Scorer proof-gates it; the shell gate does NOT load it, because
#                proof-gated superlatives are valid copy and bash cannot judge
#                proximity of proof.
#   opener       Sycophantic chat opener. Shell only; irrelevant to ad copy.
#
# The prose authority remains references/self-edit.md (EN era 1-4 + ES). This
# file is the machine-readable tripwire distilled from it.
